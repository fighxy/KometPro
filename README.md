# KometPro

Неофициальный форк [Komet](https://github.com/KometTeam/Komet) — свободного клиента для мессенджера MAX. Форк развивает цельный desktop-first интерфейс, повышает отзывчивость Windows-версии и сохраняет мобильные платформы проекта.

Проект не связан с разработчиками MAX. Названия и товарные знаки принадлежат их владельцам.

## Что изменено после форка

- Переработан desktop-интерфейс: адаптивные колонки, компактная навигация, единые поверхности, плотность и масштаб интерфейса.
- Добавлены быстрый глобальный поиск, клавиатурные команды, перетаскивание файлов и более удобная работа с широким окном.
- Поиск по каналам, контактам и сообщениям адаптирован для desktop; комментарии открываются в компактной панели.
- Обновлены сообщения, реакции и эмодзи: недавние элементы показываются первыми, Lottie-анимации загружаются бережнее.
- Улучшены голосовые сообщения: стабильная звуковая волна, раскрытие расшифровки с анимацией и аккуратные размеры bubble.
- Переработаны настройки и экран загрузок, исправлены дублирующиеся заголовки и обновление темы окна.
- Стабилизированы системный трей и обработка фокуса окна на Windows, включая старые сборки Windows 10.
- Устранены заметные обходы локализации и английские подписи в русской версии.

Подробные правила desktop-интерфейса находятся в [design/desktop-principles.md](design/desktop-principles.md), сценарии ручной проверки — в [design/desktop-qa.md](design/desktop-qa.md).

## Платформы

Основное внимание форка уделено Windows. В исходном проекте также присутствуют цели Linux, macOS, Android и iOS; полнота отдельных функций зависит от платформы.

## Сборка

Установите Flutter с Dart, совместимым с `^3.10.4`, затем клонируйте репозиторий вместе с подмодулями:

```console
git clone --recurse-submodules https://github.com/fighxy/KometPro.git
cd KometPro
flutter pub get
flutter build windows --release
```

Для другой поддерживаемой цели замените `windows` на нужную платформу.

## Участие в разработке

Сообщения об ошибках и pull request приветствуются. Для изменений desktop-интерфейса придерживайтесь существующих дизайн-токенов и проверяйте сценарии из `design/desktop-qa.md`.
