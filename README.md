# KometPro 0.7.0

Неофициальный форк [Komet](https://github.com/KometTeam/Komet) — свободного клиента для мессенджера MAX. Форк развивает цельный desktop-first интерфейс, повышает отзывчивость Windows-версии и сохраняет мобильные платформы проекта.

Проект не связан с разработчиками MAX. Названия и товарные знаки принадлежат их владельцам.

## Что изменено после форка

### Интерфейс на десктопе

- Трёхпанельная раскладка: список чатов, переписка и панель информации о чате. Ширина списка настраивается перетаскиванием, панель информации пристыковывается, когда окно достаточно широкое, и открывается диалогом, когда нет.
- Панель переписки, панель информации и поле ввода оформлены островками — скруглёнными карточками с отступом от краёв окна.
- Компактная навигационная рельса, плотность и масштаб интерфейса, единые поверхности и токены оформления.
- Пустой экран без выбранного чата показывает недавние переписки с именами и аватарами, кнопки поиска и создания чата.
- Пустой чат показывает карточку со случайным стикером вместо сухой строки.

### Управление мышью и клавиатурой

- Действия с чатом, сообщением и папкой вызываются правой кнопкой; удержание левой кнопки, унаследованное от мобильной версии, на десктопе отключено.
- Горячие клавиши: командная палитра, поиск, переход между чатами, копирование, закрытие панели. Полный список — в настройках, раздел «Горячие клавиши».
- Перетаскивание файлов в окно, вставка из буфера, прокрутка и видимые полосы прокрутки в списках.
- Меню «Создать» в шапке списка: группа, канал, контакт, папка.

### Чаты, контакты и профиль

- Поиск по чатам, каналам, контактам и сообщениям адаптирован для широкого окна; комментарии открываются в компактной панели.
- В контактах поиск фильтрует загруженный список, а добавление вынесено в отдельный модуль: по номеру телефона, по ID и вручную. Статус контакта берётся из реального presence.
- Нажатие на контакт открывает переписку в средней панели и, если позволяет ширина окна, панель информации рядом.
- ID пользователей, групп и каналов виден в карточке чата и копируется нажатием; собственный ID показан в настройках.
- Сессии устройств завершаются по одной, а не только «все остальные».

### Сообщения и медиа

- Ширина пузырей и медиа считается по ширине панели переписки, а не окна, поэтому в трёхпанельной раскладке ничего не распирает.
- Недавние эмодзи и реакции показываются первыми, Lottie-анимации загружаются бережнее.
- Голосовые сообщения: стабильная звуковая волна, раскрытие расшифровки с анимацией, аккуратные размеры пузыря.

### Звонки

- Интерфейс видеозвонков адаптирован для десктопа, сетка участников считается от реального размера окна.
- Исправлены подписки на видео в SFU, восстановление удалённого видео при устаревшей обёртке трека, надёжность управляющих data-каналов, взаимная блокировка камеры и демонстрации экрана в звонке один на один.

### Платформа и сборки

- Стабилизированы системный трей и обработка фокуса окна на Windows, включая старые сборки Windows 10.
- Встроенный апдейтер читает манифест `latest.json` из GitHub Releases и проверяет скачанный файл по размеру и SHA-256.
- Номер сборки в релизах берётся из номера запуска CI, поэтому установленная версия всегда отличима от новой.
- Файлы релиза отправляются на проверку VirusTotal, ссылки на отчёты публикуются в начале описания релиза.
- Устранены заметные обходы локализации и английские подписи в русской версии.

Подробные правила desktop-интерфейса находятся в [design/desktop-principles.md](design/desktop-principles.md), сценарии ручной проверки — в [design/desktop-qa.md](design/desktop-qa.md).

## Платформы

Основное внимание форка уделено Windows. В исходном проекте также присутствуют цели Linux, macOS, Android и iOS; полнота отдельных функций зависит от платформы.

## Сборка

Установите Flutter с Dart, совместимым с `^3.10.4`, затем клонируйте репозиторий вместе с подмодулями:

```console
git clone --recurse-submodules https://github.com/fighxy/KometPro.git
cd KometPro
flutter pub get
flutter build windows --release
```

Для другой поддерживаемой цели замените `windows` на нужную платформу. Сборки Android требуют Java 17.

Статический анализ выполняется по тем же путям, что и в CI:

```console
flutter analyze lib test tool native/komet_crypto/lib
```

## Участие в разработке

Сообщения об ошибках и pull request приветствуются. Для изменений desktop-интерфейса придерживайтесь существующих дизайн-токенов и проверяйте сценарии из `design/desktop-qa.md`.
