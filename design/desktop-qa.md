# Desktop regression matrix

## Результат этой ревизии

- 20 тестов desktop, chat layout, альбомов и видеосообщений прошли на Flutter 3.44.3 / Windows.
- Отдельно проверен `message_bubble_layout_test.dart`: 6 passed, 2 failed. Те же две ошибки воспроизведены на исходном коммите `ba9bd5d`: `a reply above a photo stays inside the photo width`, `a bubble without a header or reply still hugs its text`.
- В исходной ветке анализатор сообщает 98 предупреждений/замечаний без ошибок компиляции. Новые замечания устранены.
- Полная native-сборка, ручной visual QA и аппаратные замеры производительности не выполнены. Для сборки Flutter plugins на этой машине требуется поддержка symlink (Windows Developer Mode); настройки системы не изменялись.

## Автоматические проверки

`flutter analyze lib test tool native/komet_crypto/lib`

`flutter test test/desktop_design_test.dart test/chat_layout_test.dart test/message_bubble_layout_test.dart test/photo_album_bubble_test.dart test/video_note_layout_test.dart`

Новые тесты проверяют наследование и сохранение темы composer, переключение Material/Glossy, независимое сохранение плотности, доступное место для inspector, поиск/выполнение/отмену команд и отсутствие overflow общих поверхностей при ширине 1280, 1440, 1920, 2560 с увеличенным текстом. Это компонентные тесты, а не подтверждение качества всей работающей программы.

## Ручной приёмочный прогон

Проводить на Windows 10 1809 и Windows 11. Для каждого запуска записать ОС, GPU, версию драйвера, коммит, тему, масштаб, размер окна и результат. Не использовать реальные сообщения в тестовых артефактах.

| Ось | Значения |
| --- | --- |
| Ширина окна | 1280, 1440, 1920, 2560 |
| Масштаб интерфейса | 75%, 100%, 125%, 150% |
| Плотность | обычная, компактная |
| Тема | Material You light/dark; отдельно Glossy и Liquid Glass |
| Доступность | увеличенный системный текст, high contrast, disableAnimations |
| Inspector | закрыт, открыт, resize через границу доступного места |

- [ ] Чаты: active/selected/unread/muted/pinned различимы, hover не мигает, архивирование обратимо.
- [ ] Tab/Shift+Tab, Enter, Escape, Ctrl+K/F/N/Comma, Alt+Up/Down; выделение с Shift, копирование, контекстные меню и middle-click.
- [ ] Длинный текст, код, reply, forwarded, документы, альбомы, узкие фотографии, voice, polls; текст/доставка/реакции не перекрываются.
- [ ] Перетаскивание файлов из проводника, отмена предпросмотра, несколько файлов, удалённый файл, директория, шифрованный чат, открытые настройки/диалог.
- [ ] Настройки: поиск разделов, переключение темы, сохранение плотности и масштаба после перезапуска, dev tools отсутствуют в release.
- [ ] Отдельные скриншоты: поиск, информация о чате, окно звонка, облако, истории, Digital ID.
- [ ] Сравнить скриншоты с принятым эталоном для того же окружения. Полноэкранные golden-эталоны с реальным shell требуют синтетического account/backend fixture; компонентные тесты не заменяют эти эталоны.
- [ ] Profile-mode: длинный чат с медиа и typing, 30 секунд scrolling при закрытом/открытом inspector. Сохранить timeline, p50/p95 build/raster и число пропущенных кадров; сравнить с исходной веткой на том же устройстве.
- [ ] Windows 10 1809: неподдерживаемый Mica/shader корректно отключается; нет зависания при resize, видео и восстановлении окна.

## Аудит эффектов

`GlossyPill` сохранён для небольших контролов и выбранной glossy-темы. Общие SettingsCard/SettingsPanel больше не требуют glossy. `GlassSurface` и `LiquidGlassSurface` имеют непрозрачный fallback для системных ограничений и базовой темы. Полупрозрачность остаётся допустимой для декоративных состояний и переходов; фиксированные размеры специализированных медиаконтролов не заменяются механически токенами.

Полный аудит всех локальных радиусов, теней и эффектов второстепенных экранов, WCAG-замеры и аппаратные performance-результаты требуют отдельного визуального прогона. Не отмечать их выполненными по результатам статического анализа.
