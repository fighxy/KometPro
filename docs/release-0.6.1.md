# KometPro 0.6.1

## Звонки

- Единый управляемый поток камеры для входящих и исходящих видеозвонков.
- Последовательное переключение источников, освобождение захвата при ошибке и завершении звонка.
- Выбор окна или монитора с миниатюрами и подтверждением до начала демонстрации.
- Проверка первого кадра; контроль отключения desktop-камеры и исчезновения окна.
- Отдельные кнопки выбора камеры и микрофона; переключение передней/задней камеры на мобильных.
- Раздельные камера и экран участника в групповой раскладке, показ экрана без включённой камеры, разворачивание без обрезания.
- На Android разрешение на захват запрашивается до повышения типа foreground service. WebRTC закреплён на 1.6.0+hotfix.1 с исправлением зависания остановки Android-захвата.

Системный звук не передаётся вместе с экраном. Поддержка мобильного захвата ограничена возможностями платформы и WebRTC; полноценная системная трансляция iOS требует Broadcast Upload Extension, которого в проекте нет.

## Меню разработчика

В обычных release-сборках: desktop → Настройки → О приложении → Для разработчиков; мобильные → семь нажатий на строку версии в настройках. На экране входа — семь быстрых нажатий на логотип. В Store-flavor инструменты отключены.

## Windows

Build Windows и Release (main) создают `KometPro-0.6.1-windows-x64-setup.exe`, portable ZIP и SHA-256. Установка выполняется в профиль пользователя, с ярлыками и деинсталлятором. Постоянный AppId обеспечивает обновление существующей установки. Пользовательские данные не удаляются. Перед обновлением нужно полностью выйти из приложения, включая трей.

Visual C++ DLL включены в пакет. Отсутствующий WebView2 устанавливается из проверенного Microsoft bootstrapper; требуется интернет. Inno Setup 6.7.3 скачивается с проверкой закреплённого SHA-256. Подпись самого KometPro установщика пока не настроена.

## Проверка

Локальные тесты и сборки приложения не запускались. Изменённые модули проверяются статическим анализатором Dart, сценарий упаковки — PowerShell parser. Компиляция и упаковка выполняются GitHub Actions.

При приёмке проверить на реальных устройствах: входящий видеозвонок и выключение камеры; два монитора и отдельное окно; смену устройств; завершение звонка во время запроса разрешения; камера + экран через SFU; Android-разрешения; установку и обновление на чистой Windows. Статический анализ не подтверждает сетевую совместимость с сервером и работу физических устройств.
